# ЛЮБИМАЯ ПОДРУГА-СОСЕДКА 25.0

Интерактивный сюрреалистичный birthday experience для Ульяны. React + Vite + TypeScript + Framer Motion.

## Запуск

```bash
npm install
npm run dev
```

Открой ссылку на телефоне (или включи мобильный viewport в DevTools — экран рассчитан на ширину ~390px).

## Production build

```bash
npm run build
npm run preview   # локально проверить собранную версию
```

## Как персонализировать сайт перед отправкой Ульяне

Всё в одном месте — **`src/data/config.ts`**:

- `gifterName1`, `gifterName2` — имена дарителей (сейчас `gifterName2` уже стоит "Олеся" — впиши своё имя в `gifterName1`)
- `certificateUrl` — ссылка на настоящий сертификат (пока пусто → показывается "Сертификат скоро будет здесь")
- `videoPath` — путь к видео с Мадагаскаром (файл уже на месте)
- `videoYoutubeUrl` — запасная ссылка на YouTube, если видео не воспроизведётся напрямую
- `songPath`, `songCredit` — песня об Ульяне, которая звучит в самом конце (файл уже на месте)
- `message1`, `message2` — тексты личных поздравлений (экран "Личное сообщение")
- `postscript` — текст финального P.S.-поздравления

## Куда класть медиа

```
public/assets/
  images/         — фотографии и сюрреалистичные картинки (см. ниже)
  video/          — видео с Мадагаскаром (madagascar-birthday.mp4 уже на месте)
  audio/          — песня об Ульяне (song.ogg уже на месте)
  certificate/    — сюда можно положить файл сертификата, если он не внешняя ссылка
```

Сюрреалистичные референсы (Шрек, диско-шар, дельфин, волна, грейпфрут, тропический пляж) уже
встроены как настоящие `.jpg` — их прислали для этого проекта. Личные фото (`archive-01…04.svg`)
и одна абстрактная обложка (`archive-cover.svg`) пока остаются **SVG-заглушками** — замени их
настоящими фотографиями Ульяны. Если заменяешь на `.jpg`/`.png`, не забудь поменять расширение
в путях (`src/data/memories.ts`).

### Где добавлять фотографии из архива воспоминаний

`src/data/memories.ts` → массив `memories`:

```ts
{
  id: "005",
  title: "FILE_005",
  caption: "Подпись к фото",
  image: "/assets/images/your-photo.jpg",
}
```

Массив `anomalies` в том же файле — "сбойные" абсурдные картинки (Шрек и т.п.).
Массив `dreamFrames` — кадры сюрреалистического travel-dream монтажа перед водой.

### Факты об Ульяне

`src/data/facts.ts` — можно менять/добавлять факты.

## Структура проекта

```
src/
  components/
    SystemIntro/        — экран 1: системная загрузка
    Identification/      — экран 2: идентификация по отпечатку
    ElementChoice/        — экран 3: выбор стихии (вода — скрытый намёк)
    FactsArchive/         — экран 4: факты об Ульяне
    AchievementArchive/   — экран 5: архив достижений
    MemoryArchive/        — экран 6: архивные фото + аномалии
    SignalIntercept/      — экран 7: перехват сигнала / видео Madagascar
    PersonalMessages/     — экран 8: личные поздравления от двух подруг
    DestinationSearch/    — экран 9: поиск пункта назначения / ошибка
    TravelDream/          — экран 10: сюрреалистический travel-dream монтаж + подсказка
    WaterTransition/      — экран 11: вода заливает интерфейс (кульминация)
    GiftReveal/           — экран 12: раскрытие подарка (серфинг)
    Certificate/          — экран 13: цифровой сертификат
    FinalMessage/         — экран 14: P.S. + финальный "Case File // 25"
    shared/                — переиспользуемые примитивы (кнопки, тайпрайтер, оверлеи)
  data/
    config.ts    — имена, ссылки, тексты, тайминги (главный файл для правок)
    facts.ts     — факты об Ульяне
    memories.ts  — архив фото, аномалии, кадры travel-dream
  styles/
    globals.css     — дизайн-система (цвета, типографика, scanlines/grain/vignette)
    animations.css  — keyframes для glitch/VHS/пузырьков/волны
  App.tsx  — управляет последовательностью экранов

public/assets/  — images / video / certificate
```

## Технические заметки

- `prefers-reduced-motion` уважается: тайпрайтер печатает мгновенно, пузырьки в water-transition не рендерятся.
- Видео и сертификат имеют graceful fallback, если файлы ещё не добавлены.
- Изображения используют `loading="lazy"`.
- Вся вёрстка mobile-first, проверено на viewport 390×844.
